# 罪孽与阵营（0.8.40）

`CardSpec.sin` 和每个 `TokenSpec.sin` 为可选字段。合法值为 `null`、`wrath`（暴怒）、`lust`（色欲）、`sloth`（怠惰）、`gluttony`（暴食）、`gloom`（忧郁）、`pride`（傲慢）、`envy`（嫉妒）。新空白卡使用 `null`；旧定义缺少字段也表示未选择，不补写历史定义、不改写历史哈希。

罪孽由玩家选择，决定卡面底色和标题颜色；标题末尾仍显示所属阵营图标，保留透明背景。配色与本地图标见 `assets/sins/catalog.json` 和同目录图片；网页及游戏均使用相同深色配色，浅色标题文字。未选择时使用深灰色 `#303538`，不借用阵营颜色；阵营图标仍正常显示。卡面图片继续使用卡牌独立图片，未设置时仍可使用阵营背景。

模型必须保留玩家冻结的 `card_blueprint.sin`，不得根据名称、阵营、效果自动猜测。衍生卡的罪孽独立指定，不从母卡自动继承。罪孽不参与伤害、兵种、召唤、费用或入组许可计算。

`faction_id` 仍是独立的参考阵营字段，可以为空或省略；提供时必须引用已登记阵营。阵营检索仍然可与罪孽、类型、稀有度等检索叠加。

牌组单独保存 `main_sin`：空字符串或七个 ID，用作名义主国及卡背配色。创建牌组时选择，旧牌组默认未选择；本地保存、共享、导入、HTTP 联机和 LAN 均保留该字段。`main_sin` 不限制组牌，40 张牌和稀有度张数限制保持原规则。旧 `main_faction_id` 仅保留兼容信息。

对方可看到牌组主罪孽，但不能从未公开的手牌、伏置反制或牌库读取单卡罪孽。卡背一律使用牌组 `main_sin`，公开打出后才显示卡面罪孽。总部有独立卡牌时使用总部卡的罪孽，默认总部使用牌组罪孽。

协议：mechanics-27 / LAN 27，最低客户端 build 840。新增或变更罪孽需创建新卡牌版本；旧版本可继续查看并维持原定义。
