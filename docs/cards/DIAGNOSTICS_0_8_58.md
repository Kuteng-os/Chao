# 0.8.58 已实现：罪孽筛选、按区域回退复制、全局部署强化
transfer_card.filter.sin 支持 wrath/lust/sloth/gluttony/gloom/pride/envy/null（无罪孽），与 kind/unit_class/card_name/faction_id/min_cost/max_cost 等同时满足。忧郁坦克为 filter:{sin:"gloom",kind:"unit",unit_class:"tank"}。
transfer_card 的可选 fallback_sources 是有序后备来源列表（deck/discard/hand，最多2项，不与 source 或彼此重复），仅用于 mode:copy、destination:hand；依次检索 source 和 fallback_sources，选首个有符合筛选卡牌的区域，再在该区域内按 selection 选牌复制。不是合并三个卡池，也不是依次各复制一张；复制不移除原牌。全无匹配则不生成替代牌、不疲劳，其他效果仍结算。手牌满按现有规则处理，不再试后备区域。
示例：{op:"transfer_card",source:"deck",fallback_sources:["discard","hand"],destination:"hand",mode:"copy",selection:"random",amount:1,filter:{kind:"unit",unit_class:"tank",sin:"gloom"}}。无需编造“区域是否存在牌”的前提。
指令整场对局监听已支持：on_play 下 schedule，trigger:next_own_unit_deployed,repeat:each_event,lifetime:match，不填写 times（省略表示不限次数），effects:[{op:"modify_stats",target:"trigger_unit",unit_filter:{unit_classes:["tank"]},attack_delta:1,health_delta:1,duration:"match"}]。trigger_unit 在 schedule 内表示之后实际部署的单位，校验按内层事件判断，不是本指令。此例只影响今后友方坦克部署，既有单位、敌方单位、非坦克、召唤均不触发；永久加成随离场返场保留。不要把监听期限改为 source 或用999次代替无限次。多次使用指令可各自叠加。
CZ-000222「青春岁月」已确认：1费指令，使用时从己方牌库抽1张坦克，再将3费衍生指令【峥嵘岁月】加入手牌。【峥嵘岁月】使用时启用上述全局友方坦克永久+1/+1，并依次从己方牌库、弃牌区、手牌随机复制1张忧郁坦克到手牌。抽坦克用 transfer_card(source:deck,mode:move,selection:top,destination:hand,amount:1,filter:{kind:unit,unit_class:tank})；不是抽任意牌再检测，也不是复制坦克。衍生牌放 tokens，并用 create_card 引用。不再报告“罪孽筛选”“来源回退”“全局部署监听”缺失，不重复询问已确认的来源优先级或坦克范围。不要擅自加入全场既有坦克强化或限定只有忧郁坦克才受强化。
