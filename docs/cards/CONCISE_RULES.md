# 玩家可见规则文案

formal_text、description、提问和解释使用简洁中文。简单机制通常一句、20～60字；复杂机制按时机分行，不为字数截断。
按“前提 → 消耗 → 结果”组织，省略不存在的部分；可写“时机：条件，消耗，效果（期限）”。同一时机只写一次，同一目标用“其”承接。攻防写“+2/+2”，行动费用写“行动费-1”；己方抽牌写“抽2张牌”，敌方须注明。
例：“部署：重甲+2。”、“若敌方在场单位更多，抽2张牌。”、“阵亡：将自身的复制洗入牌库。”
指定目标写“选择一个……”，明确敌我与范围；随机、全体不改成选择。
“罪孽”指七种配色类别，“阵营”指组织，两者分开。“你”指使用者，伤害和治疗写“总部”；后场即支援阵线。行动含移动、攻击，交战含攻击、反击；指令写“使用时”，单位写“部署”。弃置进弃牌堆，消耗移出对局，均不同于消灭。
只统一描述，不改变基础攻防、当前攻防和强化规则；数值语义不明先提问，不能擅自限制当前攻击力不超过卡面值。
精简文字，不能合并、删除或重排可执行能力组与操作，尤其不能把两次伤害合为一次。主句保留目标、数值、条件、时机、随机或选择、期限。原生与当前属性、取整、特殊叠加及继承仍须准确执行，必要细节放短括号或详细说明。
“在场期间”指本次入场到离场；“永久”指本场对局离场再入场仍保留，复制继承受 inherit_from 限制。玩家要求的特殊继承或清除规则必须保留。
不展开词条教材、引擎上限、实现原理及无关例外。缺失能力和问题写入对应字段。已有名称、风味文本与基础数值不改写。

战斗规则补充（mechanics-31）：无闪击时，战斗机和轰炸机本回合移动与主动攻击互斥；额外攻击次数不豁免，反击不计入。重置行动或己方新回合清除限制。按卡面主兵种判断，额外身份不改变规则；闪击仍须满足费用、就绪、未移动及容量条件。
