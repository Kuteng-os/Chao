# 0.8.57 已实现：条件性不造成战斗伤害
set_combat_damage_multiplier.multiplier 现在允许 0..4（不是旧的1..4）；0表示只把承受此修饰的单位本次主动攻击或反击伤害归零，不禁止发动攻击，不让对方伤害归零，不跳过对方反击，不改变任何单位卡面攻击力，也不阻止独立技能伤害。
CZ-000221 用户已确认：与攻击力高于自己的单位交战时，本次攻击基数+2；否则仅本单位不造成战斗伤害。主动攻击和反击均生效。用两条互斥的 self/battle 交战修饰，均 applies_to:both、against:any：第一条 target_attack_compare:gt、multiplier:1、attack_delta:2；第二条 target_attack_compare:lte、multiplier:0。对手攻击等于自己属于第二条。比较的是此次交战前双方当前攻击力（含已有强化），不能先把+2加到自身再比较。+2仅参与本次交战计算，不改卡面，不累积。无兵种攻击力的总部不参与这一“与单位交战”的比较。
机制复述和编译都已支持，不能再报“无法归零”。不要改成己方免伤、双方均不造成伤害、禁止攻击、目标攻击归0，或把攻击力+2永久写入单位。未指定“全部伤害”时仅修饰战斗，不改变独立技能伤害。仅本单位不造成伤害已由玩家确认，不要重复询问。
