# 卡牌类型、稀有度与历史版本

当前实现：`mechanics-10`，客户端 0.8.18。制卡统一在网页工坊进行；Godot 用于收藏、组牌和对战。这里的反制为本项目已实现的伏置规则。

## 制作指令与反制

制作页「类型」可选单位、指令、反制。指令隐藏单位攻防和行动费，使用 `on_play`（打出时）效果；可以直接添加抽牌、伤害、恢复等操作，也可以填写效果要求交给 DeepSeek。模板词条按相同类型约束过滤。未确认的模型草稿不会登记。

反制使用 `kind: counter`，`unit_class: null`，`attack/health/operation_cost: 0`，`appearance.emblem: counter`，`play_target: null`。必须指定 `counter_trigger`，且展开后的能力只能使用 `on_reveal`。指令和反制至少有一个能力，均不能持有单位内置词条。

| counter_trigger | 精确触发时机 | 可用专属操作 |
| --- | --- | --- |
| enemy_unit_deployed | 对手从手牌部署单位并结算登场能力后 | trigger_unit 指向该单位；不能取消已完成的部署 |
| enemy_order_played | 对手支付指令费用、移入弃牌区后，指令效果结算前 | cancel_action 取消指令；没有 trigger_unit |
| enemy_hq_attacked | 对手支付攻击行动费、消耗攻击次数后，对己方总部造成战斗伤害前 | trigger_unit 指向攻击者；cancel_action 取消本次攻击 |

每方最多伏置 3 张。伏置时检查持有费用但不扣费。仅下一敌方回合有效，触发时再次检查并扣费，一次后弃置；余额不足不触发。下次己方回合开始未触发则原卡返回手牌，不扣费。伏置仍占手牌上限10的名额，情报和随机弃牌仍可作用于这张牌。按伏置顺序依次执行，取消行动后尚未触发的反制保留。当前反制中取消之后的其他效果仍按顺序执行。费用和攻击次数不返还。攻击者被消灭时总部不受该次攻击伤害。

伏置定义和名称仅持有者可见；对手看不到数量、动作、公共日志或手牌数变化；此前情报揭示的卡面保持显示，但不显示伏置状态。触发时公开名称与弃牌定义。手牌外召唤、技能伤害、伏置其他反制均不触发上述事件。不支持通用反应栈、反制反制、任意条件脚本。部署单位在登场结算中死亡时不触发部署反制；胜负已确定时不再触发。

反制没有场上「自身单位」，不能使用 self/chosen。trigger_unit 的数值修改、伤害、消灭仍遵循对应操作的范围、持续时间、死亡队列和预算。模型可组合这些已实现操作，也可生成独立 on_reveal 模板词条，必须照常经过预览、确认和校验。

## 稀有度与牌组

牌组固定 40 张，不包括总部。`rarity` 由玩家填写并冻结，不由模型改写。

| 值 | 名称 | 同名卡最多 |
| --- | --- | --- |
| standard | 普通 | 4 |
| limited | 限定 | 3 |
| special | 特殊 | 2 |
| elite | 精英 | 1 |

同名卡的不同版本、不同定义哈希共同计数；中央服务器也按原卡 ID 合并改名版本。混合稀有度使用这些版本中最严格的上限，不能通过混用旧版本绕过限制。名字比较使用 NFC、去除首尾空白及小写。旧定义缺失 rarity 时按普通计算，但不回填或改写定义，原始哈希继续有效。

## 作者、修订和游戏显示

服务器响应提供 `author: {id, name}`；id 为不可逆派生标识，name 为创建者显示名，不泄露登录令牌或 owner_id。作者不属于 CardSpec、编译程序或模型可填字段。管理员修改卡牌保留最初作者。

每次保存修订保留完整不可变定义、精确词条绑定及编译哈希。默认卡库按卡牌身份只显示最新版本；在游戏卡牌详情的版本列表可切换历史版本，再加入牌组。已在牌组中的旧版本保持原版本，不自动升级，即使新旧版本脚本完全相同也不能改写旧引用。新对局按所选 CardRef 精确冻结，进行中的对局不受网站修订影响。

## 验证入口

- `server/test/card_types.test.js`：稀有度、指令/反制蓝图及模板约束。
- `tests/test_counters.gd`：真实行动、取消时机、支付、一次触发、隐私、上限及确定性。
- `tests/run_mechanics_parity.mjs`：Node/Godot 校验与编译哈希对照。
- `tests/workshop_browser.mjs`：浏览器制作、预览、登记指令和反制，桌面/手机布局。
- `tests/run_cloud_store_test.mjs`：默认最新、历史选择、旧牌组引用不变。
