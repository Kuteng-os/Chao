# 巢战 0.8.50

- 新增老兵预设形态。制作单位时展开“老兵形态”，创建升级形态并配置触发条件。可快捷设置进入前线、攻击后、消灭单位后晋升，也可让指令使单位晋升。
- 老兵可拥有独立攻防、行动费、词条、效果、卡图及音效；客户端详情可查看老兵形态，升级时有提示。晋升不重置行动次数，不重复触发登场；返回手牌恢复原形态。
- 修复手牌重叠后的命中顺序，九张手牌时中间可见的卡也能选中和拖出。
- 补充攻击目标查询、击杀数前提、击杀者兵种判断、入场与攻击总部监听、每回合次数上限、临时控制、附加攻击后效果、按当前属性和位置筛选以及设置攻击力。
- 修复手牌移回牌库后的数量结算，支持一次抽取最多10张牌。
- 修复取消生成后立即重试的竞态和空白修改意见提交问题。

本批对应已验证的 CZ-000127 至 CZ-000154 中的机制与界面问题；CZ-000139 的非法数值报告和后续新报告保留待核查。原卡数据与历史版本不改写。
