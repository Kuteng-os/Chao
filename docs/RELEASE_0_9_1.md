# 巢战 0.9.1

2026-10-05 发布，build 901。正式源码位于 `.runtime/release0901`，由 0.9.0 正式版定点修改；根目录仍有未发布的视频卡开发，不直接用于正式导出。

## 本次修改

- 母卡详情增加“查看衍生卡”：卡库、手牌、场上单位和已公开场地/总部均可查看关联的单位、指令和反制。电脑右键固定详情，手机轻点卡牌；查看对应冻结版本的卡图和效果，不查询对手隐藏手牌或牌库。未获作者许可的衍生卡仍不可主动加入牌组。
- 可打出的手牌顶部增加稳定金色亮条，费用数字提亮。费用、己方回合、场上容量和合法性共同决定标记；不增加闪烁动效。
- 步兵、炮兵同回合移动和攻击互斥。坦克可以分别移动和攻击；战斗机、轰炸机仅有闪击时可执行两种行动。额外攻击次数不自动恢复移动，明确重置行动的效果仍正常生效。
- 支援阵线中的烟幕使守护失效；烟幕消失后守护立即恢复。在前线时烟幕不生效，单位可被攻击且守护正常工作。前线使烟幕无效不等于消耗烟幕，不触发失去烟幕事件；主动移动和攻击仍会正常消耗烟幕。
- 同步状态提示、词条详情、模型能力说明，以及 0.9 版本的联机更新提示。
