巢战 0.8.59

- 新增开局换牌：任选初始手牌换一次，先抽替换牌再将换掉的牌洗回牌库；双方确认后开始首回合，联机超时自动保留。
- 新增在线观战：在房间列表点击观战，或输入房间号，选择一名玩家跟随。整局视角固定，只看该玩家手牌；退出观战不会让玩家投降。
- 新增练习控制台：电脑按 F8，手机从对局菜单进入。可调费用、抽牌、添加手牌、召唤单位、查看状态与单位详情、暂停或步进 AI，并撤销最近的调试修改。
- 控制台打开时暂停练习 AI；只在本地练习生效。直接召唤不触发部署，测试部署效果可先把牌加入手牌。
- 修正联机出牌请求重试期间停止同步的问题，持续发送状态请求，缩短失败请求的等待时间，并显示具体失败原因。
- 增加服务端断线、恢复和超时结算记录，便于排查网络波动。

本次无需重建牌组；联机双方需更新至 0.8.59，才能使用开局换牌。
