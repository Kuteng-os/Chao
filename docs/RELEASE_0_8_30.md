# 巢战 0.8.30

- 弃牌支持随机或持有者自行选择，可按名称包含、准确名称、卡牌种类和兵种筛选。
- 同组弃一张后，可强化场上、手牌及牌组中的同名单位；支持攻防、行动费和附加部署抽牌等有界能力，区分本次在场和本局永久。
- 分阶段研发：从当前成果和下一阶段研发牌中选一张。三选一开发：从指定衍生卡池或己方冻结起始牌组卡池提供最多三种候选。
- 选牌显示遮罩、完整卡牌与规则，支持触屏、电脑、练习 AI、联机重连和30秒超时自动选择首项；对手不能查看候选牌。
- 衍生模板容量增加到12个；展开程序、操作次数和运行预算仍有限制。
- 指令文案改为“使用时”，单位为“部署时”，场地为“生效时”。旧卡的 on_play 规则无需修改。

前一版 0.8.29 已加入衍生卡库、作者许可入组，以及衍生卡音效编辑。0.8.28 已修复命名自定义层数。

此版本需要更新客户端至830；Windows与Android提供完整安装包及累计PCK补丁。仅处理经过验证的两条手牌选择/同名强化能力报错，原卡牌、版本和玩家账号不变；制作中的旧机制需重新“理解机制”，尚未明确的范围与持续时间仍由玩家确认。

协议：mechanics-19、frontline-lan-19；编译器和原有卡牌定义哈希保持兼容。
