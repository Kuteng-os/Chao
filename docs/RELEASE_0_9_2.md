# 巢战 0.9.2

2026-10-05，build 902。正式源码位于 `.runtime/release0902`，基于 0.9.1 定点修复。根目录仍有未发布的视频卡开发，不直接用于正式导出。

## 手机看牌

- 静止按住卡牌约 0.42 秒打开详情，松手后保持显示，可继续点击“查看衍生卡”。战斗手牌、双方公开单位、卡库卡面与牌组条目均支持；费用不足也可查看。
- 战斗时直接拖动立即进入出牌或行动流程，无需等待长按。长按查看后的松手不会出牌。
- 卡库快速滑动用于滚动；按住后移动可拖动组牌。静止长按与松手不会增删牌，电脑左键加减、右键详情保持不变。
- 修复系统取消触摸、多指输入、窗口失焦及战局状态刷新后遗留点击或放牌的问题。取消校验仅用于本地手势，不进入联网行动数据。

## 更新

Windows、Android 完整安装包与签名资源补丁位于 `build/Frontline-0.9.2.*`。资源补丁为 9,289,176 字节，最低基础 build 801，ABI `frontline-4.7-1`。旧客户端下载补丁并重启即可，账号与牌组保留。

本版只更新客户端界面，与 0.9.1 战斗规则兼容。服务器继续使用 `/opt/frontline/releases/20261005-094104-release901`、mechanics-45、最低客户端 901、局域网协议 36；发布无需重启对局服务。更新清单切换前备份，完整包与补丁均校验 SHA-256。
