# 巢战 0.8.40

- 新增七种罪孽：暴怒、色欲、怠惰、暴食、忧郁、傲慢、嫉妒。采用图标对应的较暗红、橙、黄、绿、青、蓝、紫配色，配合浅色文字。
- 罪孽决定卡牌配色，卡牌标题栏继续显示所属阵营图标。现有卡牌全部保持未选择，使用深灰色；普通卡、总部和衍生卡均可单独选择罪孽。
- 创建牌组时可选择作为名义主国的罪孽，影响牌组卡背。各罪孽与阵营的卡牌仍可自由组合。
- 阵营继续保留，可作为参考和独立筛选项；网页与游戏卡库新增罪孽筛选。
- 保存、共享牌组、对局和历史记录同步罪孽信息，保留已有卡牌版本及牌组。

Windows 与 Android 均支持客户端补丁更新。本版联机协议为 mechanics-27 / LAN 27，对战双方需更新至 0.8.40。
