# 巢战 0.8.27

mechanics-16、LAN16、最低联机版本827。由 `.runtime/release0827` 构建，未发布根目录中尚未完成的资料片扩展。

## 卡库与卡面

网页卡库改为卡牌布局：费用与行动费在标题左侧、阵营图标在右侧，攻防位于图文交界，稀有度放在底部；指令、反制、场地分别使用 !、?、△。卡图与文字约3:2，长文本精简展示，详情查看完整规则。作者、版本、修改、归档等操作收进详情。

主筛选支持搜索、类型、阵营、稀有度、费用；详细筛选支持兵种、空军/陆军、词条、作者、本人创作、攻防与行动费范围、排序，多个条件取交集。筛选保存在本地，输入只更新列表。

阵营可上传背景。卡面先用单卡图片，否则使用阵营背景；没有背景时使用阵营颜色及图标。网页与游戏使用相同优先规则。

## 机制与语句

- 卡牌、衍生卡、词条与阵营名称上限64字符，标题保留最小字号与换行提示。
- `battle` 改为“本次在场期间”；`match` 表示“永久”，随同一张牌保留整场对局，离场再入场仍在，不跨局。复制不继承附加层，抑制仍主动清除增益。
- 可组合己方/敌方/双方、前线/支援、五种兵种的在场计数条件；空军与陆军为对应兵种并集。总部、手牌、阵亡单位不计入。
- 指令与能力选择可限定兵种。相邻目标只取同阵线左右紧邻单位，不跨总部；“所选及相邻”一起锁定名单后结算，中心阵亡不会漏掉邻居。
- 邻接固定攻防、行动费、重甲光环随位置及来源变化更新；带条件的光环不允许调整防御，避免循环。
- 规则显示合并重复触发时机、同类双方效果，减少重复“然后”，不改原卡程序与结算顺序。

DSL与生成说明见 `cards/COMPOSITION_0_8_27.md`。服务端及游戏同时校验；已有卡牌不自动改写。
