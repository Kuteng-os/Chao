# 巢战 0.8.23

发布于 2026-09-26。客户端 build 823，规则 mechanics-13，局域网协议 frontline-lan-13。Windows、Android 和累计资源补丁均已发布，联机双方需更新并重启。

## 操作与卡库

- 手机长按约 0.35 秒才开始拖牌或指向；提前滑动用于滚动，抬手不误触卡牌。电脑继续直接拖动。
- 指向箭头加粗，从卡牌本体顶部中心发出，旋转和侧边状态条不改变锚点。
- 组卡加减牌只更新本地内存及相关节点，不刷新整个页面、不写文件、不发送网络请求。点击保存或上传后统一持久化；修复原先瞬间跳到顶部再恢复的问题。
- 卡库首先显示本地缓存，每次进入请求一次增量更新，仅下载新增、修改和删除信息；移除后台每 30 秒全量刷新。旧版卡牌和现有牌组继续保留。

## 机制与工坊

- 新增单卡前提树：数值比较、且、或、非；可引用双方在场单位数、手牌数、牌库数、总部防御、费用和来源单位属性等。前提在触发结算前判断，不满足则整组效果不执行。
- 前提和结果在玩家确认保存后自动校验、登记和去重，模型可复用；卡牌保存为展开后的冻结定义，不依赖可变的远程脚本。
- 支持分数战斗伤害、明确向上/向下取整、无视重甲；可分别作用于主动攻击、反击或两者。不会消耗目标重甲层数，免疫仍生效。
- “用文字添加效果”保留复述、提问、回答与修改记录；只有效果编译和校验成功后显示大号“通过”。失败后可以继续修改本次对话。
- 管理员“报错记录”持久收集生成、理解与校验问题，支持查看、导出和标记解决；重复出现会重新打开。敏感字段脱敏，不保存模型思考过程。

协议和支持边界见 [前提与结果](cards/PREMISES_AND_RESULTS.md)。根目录未完成的高级资料片机制未包含在此次发布。

## 验证

- Linux 服务器 119 项测试全部通过，无跳过，包含真实权威 Godot 工作进程。
- 前提与分数伤害 131 项；组卡滚动 99 项；牌组编辑 49 项；触摸拖动 9 项；增量缓存 19 项；云端存储 60 项检查通过。
- 战斗表现 44 项、结束结算 31 项、绑定目标与反制 181 项、场地 110 项回归通过。
- 工坊 412px 手机视口端到端验证多轮提问、成功标识、失败恢复、重载和保存；无横向溢出。
- 真实 DeepSeek API 已验证无视重甲和半额伤害的歧义提问与编译，以及敌方单位更多时抽两张的理解与编译。
- Android 模拟器实测快速滑动不加牌，长按拖动只加一张且不触发点击；正式 APK 正常进入主界面。Windows 正式 EXE 启动无脚本错误。尚未覆盖每种实机。
- 现有 60 个卡牌版本重新编译后定义及程序哈希不变；部署前后卡牌、词条、账号、阵营、共享牌组、归档状态一致。
