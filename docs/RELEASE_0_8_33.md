# 巢战 0.8.33

修复 CZ-000062—CZ-000065，并提供 Windows、Android 和累积资源补丁。联机最低客户端 833，规则版本 mechanics-21，局域网协议 frontline-lan-21。

- 按单位名称精确匹配或包含文字筛选；先筛选再随机，支持筛选后授予重甲、词条等效果。
- 按卡名去重统计场上单位，可将结果用于伤害、治疗和攻防变化。永久增益保留至返手再部署。
- 抉择支持 2—3 个互斥效果分支，控制者选择，仅执行所选分支。共用目标在出牌时选择，支持权威服断线恢复和防重复结算。
- 指令可预留下一次己方从手牌部署单位的效果，触发单位可获得闪击等。直接召唤及敌方部署不消耗。
- 阵营图标透明部分保留背景，不再绘制额外底框。网站上传时可框选、移动、缩放，支持触摸、预览、完整图片及取消。
- 修复选择界面提示栏过高与遮挡。包含 0.8.32 的固定滚动更新窗口、网页卡面和阵营颜色修复。

机制边界：名称筛选用于触发效果；不支持任意持续群体光环。抉择限使用/部署时，每效果组一次，不嵌套，仍计入操作预算。卡牌数值、时长、同名目标及未来入场范围需作者确认后生成；本次不会改写玩家已登记的卡牌。

验证：服务器完整套件 147 项（首次旧版本断言修正后，相关 15 项重跑通过）；18 套 Godot 机制回归通过，其中新机制 163 项，真实 DeepSeek 8/8 复述/生成验证，生成结果再跑 163 项跨运行时及结算检查；20 项选择界面与透明绘制检查。网页 360/412/1440 宽度裁剪及透明导出、触摸检查；实际网站本地隔离服务上传/保存/重载通过，无 CSP 错误。Windows、Android 模拟器启动通过，0.8.31 基座加载签名 0.8.33 补丁通过。未宣称实体手机全面验证。

线上已有 142 个卡牌版本、3 张衍生卡重新编译哈希一致。CZ-000065 的此前通用处理说明保留在历史，本次改为具体修复说明和版本，向相应作者发送站内信。

未发布的其他原版机制仍保留在工作区。本次从隔离的 .runtime/release0833 构建，未将那些开发中的能力混入发布。
