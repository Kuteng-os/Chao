# 巢战 0.9.4

- CZ-000281：新增重甲 v2，参数 1～100，实际重甲层数上限 100。v1 定义和已有卡牌版本保持原样；编辑旧草稿时，移除旧重甲并重新添加即可使用 v2。
- CZ-000282：固定受伤修正支持 -100～100。减伤 100 遇到 101 点伤害仍承受 1 点，不等同于免疫；战斗限定不影响技能伤害。
- CZ-000283：新增交换攻防。支持选择任意一方场上单位，原子交换当前攻击力与剩余防御力，持续本次在场期间；攻击力为 0 时交换后防御力为 0，正常阵亡。总部不可选。交换后受伤、治疗、光环变化和再次交换正常结算，离场后失效。
- 网页效果编辑、模型能力说明、衍生卡及词条模板同步支持新规则。扩大参数范围时仍限制最多 65,536 种校验组合，防止卡住生成服务。
- 联机双方需更新至 0.9.4（mechanics-47）。原有账号、卡牌历史版本和牌组保留。

仍保留待处理：CZ-000139 缺少原始卡牌数据；CZ-000189 引用已不存在的词条，需要作者补齐；CZ-000204 等待作者确认“阵亡：自身 +3/+1”的实际意图。
