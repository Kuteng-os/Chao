# 巢战 0.8.22

发布于 2026-09-25。客户端 build 822，规则 mechanics-12，局域网协议 frontline-lan-12。Windows、Android 和累计资源补丁均已发布，联机双方需更新并重启。

## 功能

- 每张卡及衍生模板可配置选中、抽牌、出牌、攻击、移动、受伤、治疗、阵亡、效果触发音效。未设置时沿用默认表现，支持试听、更换和恢复默认。
- 场地卡使用三角标识，可编入牌组或生成到手牌；双方共用一个场地，新卡替换旧卡，旧场地进入弃牌堆。场地不占阵线格，不计入单位数。
- 场地可设置战场背景、背景音乐及登场、双方回合触发效果；支持随场地生效/失效的持续攻防、行动费和重甲加成，覆盖后来入场的单位。
- 新场地没有设置背景或音乐时恢复默认。音乐渐变切换，重复快照不会重播，过期下载不会覆盖当前场地，退出战斗恢复菜单音乐。
- 工坊转换音频为标准 PCM WAV，音效最长 12 秒，音乐最长 300 秒。客户端验证哈希、缓存资源、限制并发；音量、静音和后台静音仍有效。下载失败不影响战斗结算。

详细定义和支持范围见 [场地与音效接入文档](cards/FIELD_AND_AUDIO.md)。此次未发布根目录中的高级资料片机制草稿。
