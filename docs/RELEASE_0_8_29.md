# 0.8.29 衍生卡卡库

衍生模板以稳定独立身份进入网页及游戏卡库，来源卡修订时更新，历史版本冻结。默认不可主动入组；作者在衍生卡编辑中选择允许加入牌组后，按稀有度限制构筑。服务端共享/联机、离线构筑与客户端拖放都校验。允许入组不产生额外生成者。

从卡库点修改进入衍生卡独立编辑页，改名称、数值、许可、稀有度、词条、效果与各类音效；保存创建来源卡的新修订，旧音效仍随旧版本保留。移除自定义音效恢复默认。原始3类衍生模板限制暂保持。

来源归档则衍生卡隐藏、旧牌组可用；来源新修订移除模板则仅历史保留；彻底删除来源时共享牌组失效并同步清理关联衍生身份。

验证：137 Node 测试；536 Node/Godot 校验一致；265自定义层数检查；49构筑交互检查；14衍生卡客户端检查；真实网页音频上传、恢复默认、保存与4种分辨率。
