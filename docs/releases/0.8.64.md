# 0.8.64：第二期

- 已有卡牌及其历史修订属于第一期，新登记卡牌默认第二期。
- 修改保留原卡的期数，衍生卡继承来源卡的期数。
- 期数是分类元数据，不为卡名加前缀，不在卡面、卡库条目或详情中显示标签。
- 网页和游戏支持期数筛选，可与现有筛选叠加。两期可自由组牌。

## 数据兼容

`series` 位于登记记录，`card_series.current` 位于服务器状态；二者均不进入 CardSpec、战斗编译及冻结哈希。迁移不更改账号、牌组、效果、图片或历史版本。旧客户端仍兼容 mechanics-44；客户端增量同步会更新同版本卡牌的期数元数据。

## 验证

- 服务器集成：中央 HTTP 状态与公开卡库的期数一致；旧版本与归档迁移、重启幂等、新卡与修订、来源衍生、云端同步去重、组合检索、增量指纹。
- Godot：期数及缓存 30 项、卡库操作 37 项、阵营与布局 72 项、滚动及拖入 100 项，均通过。
- 浏览器：真实保存进入第二期、卡名无前缀、无常驻标签、筛选持久化、桌面单行及手机/平板宽度。
- Windows 完整安装包与 0.8.31 基础客户端签名资源补丁启动；Android 安装包签名验证。

历史 UI 测试夹具已同步现有“罪孽主国”和先建牌组再拖卡的流程。

## 发布

已部署 0.8.64。迁移 238 种卡牌、738 个历史版本；公开卡库含 28 张衍生卡，合计 266 张均属于第一期。期数外的数据逐项比较保持一致。

完整服务器回归覆盖 250 项：首次旧版本断言已更正；联机 25 项和最终 HTTP／期数 15 项复测全部通过。
