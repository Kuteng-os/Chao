# 0.8.65：牌组构筑

- 卡库左键点击加入一张，牌组列左键点击移除一张；右键打开详细信息，原有拖动操作保留。
- 新建牌组选择初始罪孽及附属罪孽，二者仅作标识，所有卡牌仍可自由组合。
- 新增“我的牌组”，支持本地保存、编辑、重命名、删除及导入。加减牌不请求服务器、不重建卡库，不改变滚动位置。
- 卡库更新后，当前牌组、已保存牌组及其总部自动使用最新卡牌版本。共享牌组导入时也解析最新版。
- 历史卡牌及已经开始的对局仍保留原来的定义。更新导致稀有度限额变化时保留牌数，调整后方可对战。

本次不改变战斗规则或卡牌效果，不需要数据迁移，兼容 mechanics-44。

验证：真实鼠标点击与右键、拖动、滚动稳定性、新建/保存/切换/重启、总部及历史版本、HTTP 增量缓存和共享牌组兼容测试。
