## 验证证据

- 服务端完整测试在 Linux 运行；新增机制另有 Godot 与 Node/Godot 交叉校验，详见 RELEASE_0_8_25.md。
- 生产 97 个历史版本重新编译，定义哈希与程序哈希不变。
- 第二轮真实 DeepSeek 九个样例通过并人工复查结构；首轮发现的数量比较反转已加入有限修复和回归检查。这不代表任意自然语言都能无误生成。
- Windows 完整包与 Android 模拟器启动通过；未覆盖所有真实机型。本轮网页检查以接口和代码测试为主，未完成独立浏览器视觉验收。
- 外部模型服务仍可能短暂不可用；全服务器卡库随机生成尚未开放。新的故障将继续收录。
