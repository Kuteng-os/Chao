# 巢战 0.9.0

2026-10-04 正式发布，build 900。此前的本地预览限制已由用户“可以发布了”解除。

正式源码位于 `.runtime/release090`，由 `.runtime/preview090` 定版；主项目根目录仍含另一轮未发布的视频卡开发，不可直接从根目录导出替换正式版。预览目录与独立预览存档继续保留。

## 本次内容

- 都市风格主界面、中性灰配色、透明战斗信息区，雨夜天台和晨光作战室场景。
- 更大的卡图、自然金属反射、罪孽底色与阵营水印。单位名称置顶，指令名称和描述居中，中文和英文分别适配。
- 按住拖动瞄准、抽牌翻面展示、落牌与手牌重排动画，修复选中、移动和抽牌闪动以及指令遮罩层级。
- 共享卡牌字体和文字布局缓存，限制卡面控件及渲染缓冲的回收池大小，减少重复生成和分配造成的停顿。
- 首页随机卡牌轮播，悬停、聚焦和详情打开时暂停。
- 保留本地组牌、左键加减牌、右键详情和服务器卡牌版本同步。

## 安装和更新

Windows：`build/Frontline-0.9.0.exe`，118,349,392 字节。

Android：`build/Frontline-0.9.0.apk`，87,290,613 字节。沿用 `cn.projectsun.frontline` 包名和既有签名，versionCode 900。

签名累计补丁：`build/Frontline-0.9.0.pck`，9,303,620 字节。最低基础 build 801，ABI 仍为 `frontline-4.7-1`。正式版使用原有 Windows 档案目录和 Android 应用数据；独立预览档案不自动覆盖正式档案。

玩家可在游戏设置中检查更新，下载补丁后重启；也可从工坊的客户端下载入口安装完整包。`start.cmd` 现在优先运行 0.9.0。
