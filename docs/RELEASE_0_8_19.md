# 0.8.19：练习结算与指令拖放

- 修复练习出牌时，状态通知与界面主动刷新重复提交同一结束快照，导致动画完成后跳过胜负弹窗的问题。排空重复快照后仍进行结算，弹窗保持唯一。胜利、失败均可返回作战准备。
- 无需选择目标的指令与反制不显示指向箭头，拖到战场即可出牌。指定目标指令、普通攻击保持原有指向提示。
- 手牌从上一版位置下移 12 个逻辑像素，为支援阵线底部留出间距。

本版仅修改客户端 `scripts/ui/battle_view.gd`；沿用 mechanics-10、LAN 10 和 build 818 服务端门槛。旧规则、卡牌定义与账号数据不变，补丁包含 0.8.18 的全部修复。

验证：原版问题在重复快照用例中重现；修复后 Windows 31 项结算与交互检查通过，包括两种胜负结果、返回流程、重复弹窗防护、无目标指令拖放与手牌位置。

发布：0.8.19 / build 819 已上线，签名资源补丁 8,317,912 字节；公网清单与补丁哈希核对通过。Windows 和 Android 模拟器各31项结算交互检查通过，原战斗表现回归44项通过。安卓版正式补丁从0.8.1基础包启动成功，启动确认完成，无脚本错误；未进行手机真机验证。
