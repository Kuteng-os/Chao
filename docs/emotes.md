# 表情与启动加载（0.8.49）

工坊的“表情库”可上传 GIF / PNG、改名和删除自己的表情，管理员可管理所有表情。透明像素保留，GIF 循环播放。单张文件上限 4 MiB、1024 × 1024、120 帧，解码总像素上限 32 Mi；最终按比例缩至最长边 160 像素。每个作者最多保留 48 个可用表情。图片处理在有内存和时间限制的独立 worker 中完成。

游戏指挥部、设置和局外“表情设置”可配置八个位置。点击位置，再选表情，最后保存。轮盘先存本地，再与账号同步；账号和服务器之间隔离。工坊仅管理上传素材。删除表情会清空对应位置。

电脑按住 T 呼出轮盘，摆动鼠标选择方向，松键发送；默认快捷键可改为字母键或 F1～F12。手机按住表情按钮并拖至发送位置，停留 0.24 秒呼出轮盘，再滑向表情并松手发送。滑回中心取消，也保留点击选择模式。表情出现在呼出位置，坐标按战场比例同步，双方视角上下翻转。轮盘在屏幕边缘会内移，发送位置仍保留原始呼出点。空位不发送。可连续快速发送（仅有 80 毫秒的防抖），小表情约显示 1.9 秒并可叠加，屏幕最多保留 32 个；可屏蔽对方表情。练习显示本人的表情，云端和局域网会传给对手。表情不属于战斗命令，不改变状态序号、费用、行动或对局统计。局域网协议为 frontline-lan-32，双方需使用本次客户端；云端战斗规则仍为 mechanics-31。

每次启动都会显示加载页，检查卡库增量、表情目录、账号轮盘及已选表情素材、签名更新清单。只有完成对应请求后才推进进度。8 秒后可提前使用本地数据进入；请求继续在后台执行。失败时提供重试和本地进入，发现客户端更新时打开已有更新面板。未自动安装或跳过签名检查。

## HTTP 接口

- `GET /v1/public/emotes`：公开目录，含作者、帧尺寸、列数、逐帧毫秒时长、PNG atlas SHA-256。
- `GET /v1/emotes/assets/:sha256.png`：不可变的透明 PNG atlas；只提供已登记哈希。
- `POST /v1/emotes`：登录后上传 `{name, image_base64}`。
- `PATCH /v1/emotes/:id`：作者或管理员改名 `{name}`。
- `POST /v1/emotes/:id/delete`：作者或管理员移除 `{}`；清除账号引用，保留不可变文件以兼容正在显示的动画。
- `GET /v1/emote-loadout`、`PUT /v1/emote-loadout`：当前账号的 `{slots: [八个 UUID 或空字符串]}`。
- `POST /v1/rooms/:id/emotes`：成员发送 `{request_id, emote_id, point: [x,y]}`（位置可省略，两个数均为 0～10000 的整数，表示相对坐标万分位）。服务器鉴权、冷却和去重；快照附带独立的 `emote_events`，只返回最近 5 秒、最多 64 条。客户端即使收到相同战斗状态序号也处理新表情，按事件序号去重。

GIF 使用 `gifuct-js 2.1.2`（MIT）解码；PNG 使用现有 `pngjs`。GIF 合成支持透明像素及 disposal 2 / 3。客户端校验 atlas 哈希与尺寸，持久缓存文件，内存最多缓存 12 张 atlas。

对局轮盘直径为桌面 224、手机 260 个布局像素，表情为 72 × 72。电脑松键或手机松手发送，环中心取消，窗口失焦取消，打开其他弹窗时不响应表情快捷键。

## 0.8.48 修订
网页仅上传、预览、改名和删除表情，不再编辑轮盘。轮盘仅可在游戏局外配置。局内手机保留呼出按钮，电脑不显示表情或设置按钮，仅用配置快捷键。发送的小表情有±12px水平、±8px竖直偏移及±8度倾斜，约1.9秒内上浮24—34px并淡出；视觉随机数独立于战斗随机序列。局域网协议升级为frontline-lan-33。

## 0.8.49：快捷重发
发送表情后，再次按住 T（或自定义快捷键），未选中新表情便松键，会在本次呼出位置重发上次表情。选中新表情则更新记录，轮盘中心显示“重发上次”。首次未选表情不发送；空位置、Esc、右键、失焦仍可取消。手机中心仍取消。记忆仅保存在当前会话，界面重建不会丢失；切换账号或服务器会清空，上次表情已被移出轮盘或删除时不重发。不改变既有发送频率。

## 作者倍率与战场预览
工坊上传时或表情的“战场预览”中，作者和管理员可设置0.25～2倍大小。1倍为总部卡宽度156个布局像素，按表情长边计算，原有表情默认0.46倍（约72像素）。轮盘图标大小不受此设置影响。模拟战场与客户端均按1440×900布局及156×214总部比例绘制，可点击预览位置，查看随机错位、偏转、上浮与淡出；保存后所有玩家使用作者设定。

上传与PATCH接口增加可选整数 `scale_percent`（25～200，100表示1倍，缺省46）；PATCH可仅提交倍率，旧改名请求仍兼容。服务器在发送事件中冻结该整数，双方收到同一数值，不受本地表情目录缓存新旧影响。局域网由主机提供统一倍率，协议更新为frontline-lan-34，双方需更新客户端。云端仍为cloud-1，战斗规则仍为mechanics-32。
