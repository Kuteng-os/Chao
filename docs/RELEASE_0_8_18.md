# 0.8.18：效果选目标与隐蔽反制

本版规则修订 `mechanics-10`，对局最低客户端 build 818，直连协议 `frontline-lan-10`。

- 阵亡、己方回合开始/结束的指定目标效果，默认在部署或召唤入场时选择。以战场实例绑定；移动阵线不改变目标，离场后失效，同卡重新入场也不会替代原目标。无关效果照常结算。没有合法目标时不阻塞。
- 能力组 `target.timing` 可填 `deploy` 或 `trigger`，延迟效果省略时为 `deploy`；明确要求触发时选择的机制使用 `trigger`。网页编辑器及 DeepSeek 规则摘要同步。旧卡定义和编译哈希不改写。
- 效果选目标显示黑色半透明遮罩、明确提示及合法目标高亮；普通攻击与移动不加遮罩。已提交部署不能取消目标选择，尚未出牌的预选可取消。
- 反制伏置时须有足够费用，不扣费；对手看不到动作、反制数量、公共日志或手牌数量变化。仅下一个敌方回合有效，成功触发时再次检查并扣费；费用不足则不触发。下次己方回合开始，未触发反制原卡返回手牌，不收费用。
- 多张反制按伏置顺序触发，取消行动后其余反制保留。已离场的部署/攻击单位不继续触发针对该单位的反制。伏置牌仍占手牌上限，仍可被情报及随机弃牌影响；情报不暴露伏置状态。
- 桌面端鼠标离开手牌即关闭详情，取消尚未出现的悬停预览；切到另一张牌不会被旧事件误关。手机仍为点击查看。
- 自己手牌上移 24 个逻辑像素；双方指令及触发反制增加短暂卡面展示。显示使用实际打出的冻结定义，不访问对方隐藏手牌。
- 单位布局、指向线及打击位置以卡牌本体居中，右侧效果标记不影响中线。

补丁适用于 0.8.1 基础安装包；Windows 和 Android 共用签名资源补丁。未完成的扩展机制不包含在本版。
